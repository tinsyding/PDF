# PDF 无损反色（纯前端离线版）

一个极简、零构建、纯前端本地运行的 PDF 反色网页工具。所有解析与反色均在浏览器本地完成，文件不会上传至任何服务器。

## 核心特性

- **无损矢量反色**：不进行光栅化，直接基于 PDF 规范的 `/Difference` 差值混合模式原地修改选中页面，文字依然锐利清晰、可选中、可搜索，文件体积几乎不膨胀。
- **保留原始结构**：仅对勾选页面执行原地反色，未选中页面保持原样，完整保留原 PDF 的目录书签、超链接与元数据。
- **缩略图自由选页**：
  - 上传后默认全选，点击缩略图即可切换并实时预览反色效果；
  - 支持 `Shift` 连续多选、全选 / 全不选 / 反选 / 奇偶页，以及页码范围输入（如 `1-3, 5, 8-10`）；
  - 基于 `IntersectionObserver` 懒加载缩略图，几百页 PDF 也能流畅浏览。
- **完全离线可用**：已内置 `pdf-lib` 与 `pdf.js` 本地压缩库，不依赖任何外部 CDN。

## 反色原理

对于每一张选中的页面，在 PDF 对象层级原地构造三层叠加：

1. **底层**：绘制覆盖整个 `MediaBox` 的纯白矩形（补齐 PDF 默认透明背景）。
2. **中间层**：将原页面内容流封装为 `Form XObject` 并配置 `/DeviceRGB` 透明组。
3. **顶层**：使用 `ExtGState`（`/BM /Difference`）叠加全页纯白矩形。依据混合公式 $|C_b - 1| = 1 - C_b$，实现精准无损反色。

## 使用方法

直接用浏览器打开 `index.html`，或在项目目录下启动任意静态文件服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080` 即可。

## 目录结构

```text
.
├── index.html            # 页面结构
├── style.css             # 纯深色护眼主题样式
├── js/
│   ├── pdf-inverter.js   # 无损矢量 PDF 反色核心引擎
│   └── app.js            # 缩略图懒加载与选页交互逻辑
└── vendor/
    ├── pdf-lib.min.js
    ├── pdf.min.js
    └── pdf.worker.min.js
```
